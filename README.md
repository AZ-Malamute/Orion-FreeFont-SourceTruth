# Orion Source of Truth — Free Font

**Orion Source of Truth — Free Font** is a free, open-source type identity for source-truth work, improbable documentation, creative production systems, and human-readable evidence.

It began as a font that did not yet exist.

Now it exists.

## Current status

Early prototype stage.

Installable font files now exist:

- `fonts/OrionSourceTruth.ttf`
- `fonts/OrionSourceTruth.otf`
- `fonts/SHA256SUMS.txt`

These are early generated releases intended to establish the project structure and workflow.

Future versions will improve glyph design, spacing, kerning, character coverage, visual identity, specimen quality, and documentation.

## Design language

Orion Source of Truth is inspired by source-truth documentation, film leaders, metrology reports, Git receipts, SHA-256 hashes, NASA-console clarity, deep ultramarine / Orion Source of Truth Blue, and loyal witness energy from Orion.

## Color note

The early specimen uses a deep ultramarine blue as a respectful visual homage to the emotional force of Yves Klein’s blue work and to Greg Gasson’s long personal connection to that color.

This project is not affiliated with, endorsed by, licensed by, or associated with the Yves Klein estate, Archives Yves Klein, or any related rights holders.

As the project develops, the public color name may become **Orion Source of Truth Blue**.
