# Orion Source Design Notes

Orion Source is a concept-stage type identity.

## Purpose

Make improbable work readable.

## Core feeling

NASA console + film leader + Git receipt + metrology report + loyal dog tag + Orion Source Blue.

## Signature phrases

- The workflow is the evidence.
- Imperfection delivered on time.
- Source truth, rendered cleanly.
- I’m not crazy. I’m improbable — and increasingly well-documented.

## Current status

This repository currently contains the first public specimen PDF. It does not yet contain installable font files.
